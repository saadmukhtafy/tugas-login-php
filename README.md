# README – LOGIN ADMIN

## Cara Menggunakan Program

### 1. Persiapan
- Pastikan aplikasi Laragon sudah terinstal.
- Siapkan seluruh file program:
  - `login.php`
  - `masuk.php`
  - `login.css`
  - `logo.jpg`

### 2. Menjalankan Program
1. Buka aplikasi Laragon.
2. Jalankan Apache.
3. Simpan folder program ke dalam:

   `C:\laragon\www\`

4. Buka browser.
5. Masukkan alamat berikut:

   `http://localhost/nama-folder/login.php`

### 3. Login Admin

Gunakan akun berikut:

- **Username:** admin
- **Password:** 12345

### 4. Proses Login
1. Masukkan username.
2. Masukkan password.
3. Klik tombol Login.
4. Jika akun benar, program akan menampilkan halaman Selamat Datang.
5. Jika akun salah, program akan menampilkan pesan kesalahan.

### 5. Catatan
- Pastikan Apache dalam keadaan aktif.
- Pastikan semua file berada dalam satu folder.
- Jangan mengubah nama file tanpa menyesuaikan alamat pemanggilannya.
- Program ini menggunakan PHP Session untuk menyimpan status login.
